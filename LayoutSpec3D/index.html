LayoutSpec3D:
3D Scene Generationwith Structured SceneDescriptions andInstance-Level Asset Integration

Structured scene descriptions,asset-aware geometry, andrelation-preserving static rectificationfor text-driven 3D scene generation.

Abstract

Text-driven 3D scene generation needs to turn object requirements, spatial relations, and static geometric constraints into usable layouts. Data-driven and large-model methods often yield omissions, unmet relations, collisions, and boundary violations after numerical layouts are grounded in 3D assets. We propose LayoutSpec3D, a configuration-driven framework for scenes with explicit object requirements, spatial relations, and boundary conditions and sufficient asset coverage. It converts text, scene dimensions, boundaries, and domain configurations into a structured scene description, then builds a 3D asset record from each selected asset's geometry to rectify support, collision, and boundary constraints.

LayoutSpec3D-FTCE fixes prompts and scene metadata, maps outputs to a common canonical scene, and applies shared final-scene checks. The framework delivers more complete and relation-consistent layouts while reducing geometric conflicts and preserving intended spatial relations.

LayoutSpec3D Overview

LayoutSpec3D uses domain configurations, instance-level assets, and static constraints to construct the description, map assets, rectify geometry, and recheck relations.

01

Inputs

Text request, scene dimensions and boundaries, domain configuration, and available 3D assets.

02

LLM Compilation

During language-model compilation, the request yields a structured scene description and an initial layout with shared instance identifiers.

03

Structured Scene Description

The description records declarative requirements, while the layout sets each instance's position, scale, yaw, and anchor.

04

Asset Mapping

Each instance is bound to a candidate 3D OBJ asset from its category-specific candidate set.

05

Static Rectification

Static rectification checks support, collisions, and boundaries while preserving declared relations.

Geometric Rectification

Resolve local conflicts while preserving intended relations

After asset instantiation, staged geometric rectification resolves collisions, boundary violations, support violations, and floating objects while preserving intended spatial relations. The structured scene description and 3D asset records remain traceable before and after rectification.
